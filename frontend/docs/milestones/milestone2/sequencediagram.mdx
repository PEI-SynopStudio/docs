## User Story 03 (US03)
*As a Content Creator, I want to upload a long video directly from my computer, so that I can work with recordings that only exist locally.*

```mermaid
sequenceDiagram
    autonumber
    participant W as Web App
    participant A as API
    participant M as Message Broker
    participant K as Worker
    participant D as Database
    participant O as Object Storage

    Note over W,O: PHASE 1 - Upload session
    W->>A: Request upload session
    A->>D: Check project and licence confirmation
    D-->>A: Project record
    break Project not found or licence not confirmed
        A-->>W: Rejected, processing blocked
    end
    A->>A: Validate extension and MIME type
    break Unsupported format
        A-->>W: Rejected, processing blocked
    end
    A->>O: Create multipart upload
    O-->>A: Upload ID
    A->>D: Save source record
    A-->>W: Upload ID and pre-signed URL for each chunk

    Note over W,O: PHASE 2 - Chunked transfer
    loop For each chunk
        W->>O: Upload chunk (pre-signed URL)
        O-->>W: Chunk confirmation (ETag)
        opt Chunk upload fails
            W->>O: Retry the same chunk
        end
    end

    Note over W,O: PHASE 3 - Completion and dispatch
    W->>A: Complete upload
    A->>O: Complete multipart upload
    O-->>A: File assembled in staging storage
    break Assembly failed or file incomplete
        A->>D: Set source status "Upload Failed"
        A-->>W: Error
    end
    A->>D: Update source record
    A->>M: Publish ingestion job
    A-->>W: 202 Accepted

    Note over W,O: PHASE 4 - Inspection and processing
    M->>K: Deliver ingestion job
    K->>O: Read raw media
    K->>K: Inspect integrity
    alt Corrupted file or no valid audio track
        K->>M: Publish "ingestion failed"
        M->>A: Deliver event
        A-->>W: Error message
    else File is valid
        K->>M: Progress event
        K->>K: Extract audio (16 kHz mono WAV) and other attributes. Generate clips
        K->>O: Store clips
        K->>M: Publish "ingestion completed"
        M->>A: Deliver event
        A-->>W: Ingestion complete
    end
```

## User Story 04 (US04)
*As a Content Creator, I want to import a video from an authorized link, so that I do not have to download the recording and upload it again.*

```mermaid
sequenceDiagram
    autonumber
    participant W as Web App
    participant A as API
    participant E as External API
    participant M as Message Broker
    participant K as Worker
    participant D as Database
    participant O as Object Storage

    Note over W,O: PHASE 1 - Link submission and validation
    W->>A: Submit link
    A->>D: Check project and licence confirmation
    D-->>A: Project record
    break Project not found or licence not confirmed
        A-->>W: HTTP error response: processing blocked, licence required
    end
    A->>A: Validate URL syntax and domain
    break Invalid URL or unsupported domain
        A-->>W: HTTP error response
    end

    Note over W,O: PHASE 2 - Asynchronous dispatch
    A->>D: Save source record
    A->>M: Publish ingestion job
    A-->>W: 202 Accepted 

    Note over W,O: PHASE 3 - Retrieval from the external platform
    M->>K: Deliver ingestion job
    K->>E: Fetch audio and video stream
    alt Source unavailable during download
        E-->>K: Error
        K->>M: Publish "ingestion failed"
        M->>A: Deliver event
        A-->>W: Send WebSocket notification
    else Download completed
        E-->>K: Media stream
        K->>O: Store raw media in staging storage

        Note over W,O: PHASE 4 - Inspection and processing
        K->>K: Inspect integrity with FFprobe (headers, corrupted packets, audio track)
        alt Corrupted file or no valid audio track
            K->>M: Publish "ingestion failed"
            M->>A: Deliver event
            A-->>W: Send WebSocket notification
        else File is valid
            K->>M: Progress event ("Extracting Audio")
            M->>A: Deliver event
            A-->>W: Send WebSocket notification
            K->>K: Extract audio (16 kHz mono WAV) and other attributes. Generate clips
            K->>O: Store clips
            K->>M: Publish "ingestion completed" 
            M->>A: Deliver event
            A-->>W: Send WebSocket notification: ingestion complete
        end
    end
```
